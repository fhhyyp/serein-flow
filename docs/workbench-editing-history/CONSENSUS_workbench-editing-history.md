# Web 工作台编辑历史与本地工作副本共识

> 阶段：Consensus / Approve 完成。用户的自动执行授权满足本轮确认门禁。

## 验收标准

- 新增节点、节点拖拽、连线、删除、参数来源/属性编辑、新增画布和删除非主画布都可撤销和重做。
- 撤销后发生新的编辑时，重做历史必须清空；历史最多保留 50 项；没有可用历史时对应命令禁用。
- `Main` 不可删除；`Init`、`Loading`、`Exit` 各最多存在一个，菜单只显示尚未创建的生命周期画布。
- 保存后刷新页面可恢复画布、节点、边、参数来源、活动画布和节点 ID 序号；损坏快照不阻止应用打开。
- 本地尚未保存时显示未保存状态；保存后显示已本地保存。不得标示为后端或云端保存。
- 快捷键在非文本编辑区域可用；文本输入/文本域/下拉框内只保留浏览器本身的编辑撤销行为。
- `vue-tsc` 和 Vite 构建通过；375px 页面无横向溢出，动态 ARIA 状态与按钮禁用状态一致。

## 技术约束

- 历史模块为纯 TypeScript，不耦合 Vue Flow；快照通过 JSON 安全深拷贝构造。
- `localStorage` 使用键 `sereinflow.workspace.v1`，包含 `formatVersion`，不得保存任何脚本源、令牌或外部 DLL。
- 仅工作副本状态写入浏览器；生产流程真源和运行状态仍将由 T8 API/SQLite 管理。
- 使用现有 Lucide 图标、语义化 `button`、0-4px 圆角和浅色 Swiss 视觉令牌。
