# 项目与流程

**项目**是一个工作区。你可以在里面维护流程、选择要用的节点类库，并查看运行。**流程**则是工作区中的执行步骤：它记录了画布、节点、连线和从哪个节点开始。

## 新项目为什么是空的

控制台创建项目时，会同时创建一张空白的“主流程”画布。这个草稿可以保存，但还不能运行：没有可执行的节点，也没有入口。拖入节点并指定入口后，它才成为可运行的流程。

## 一条流程里有什么

- **画布**：放节点的区域。主流程是默认画布，还可以有其他画布。
- **节点**：一次动作，例如执行脚本或调用另一个画布中的流程。
- **流程连接**：决定下一个执行谁。
- **数据连接**：把上游节点的值交给下游参数。
- **入口节点**：普通流程从这里开始。

画布上看得到的内容，保存后会成为流程定义。程序读取 `GET /api/projects/{projectId}/flows/{flowId}`，得到的就是这一份定义。

## 什么时候用哪个接口

先用 `GET /api/projects` 找到项目和流程 ID。需要看流程细节时，再用 `GET /api/projects/{projectId}/flows/{flowId}`。修改流程时，控制台会带上当前版本号；若别人先保存了，服务器返回 `409`，提醒你先读取新版本。

自己拼装流程定义需要同时处理节点、端口、连接和校验。刚开始建议在控制台画好，再用 API 读取和运行。具体路径见[项目与流程 API](/api/projects)。
