# 公开流程接口

如果别的程序需要调用某条流程，可以为它建立一个**公开流程接口**。外部程序只需记住接口 ID，不用直接操作内部的画布或版本。

## 从流程到公开调用

顺序是：先保存流程，再[发布生产版本](/modules/versions)，然后创建公开接口并启用它。没有生产版本的流程不能创建公开接口。

接口可以设置为**同步**或**异步**调用。同步模式会等一小段时间，若流程及时完成，直接返回结果；等不及就返回任务 ID。异步模式立即返回任务 ID。两种情况下，你都可以用任务 ID 继续查询。

## 外部程序需要传什么

调用地址是 `POST /api/public/flows/{interfaceId}/invoke`。请求体中的 `projectInputs` 是一个 JSON 对象，键名由你的流程输入决定。若 REST 鉴权已启用，调用方需要有 `run.execute` 权限；查询任务需要 `run.read`。

接口被关闭、删除，或生产版本不可用时，调用不会正常启动。创建、更新、调用和查询的完整路径见[公开流程接口 API](/api/public-interfaces)。
