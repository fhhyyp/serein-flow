# 环境设置与密钥

流程能不能顺利运行，除了流程内容，还取决于服务一次能接多少任务、同时执行多少任务。环境设置管理这些数字；密钥则决定谁能调用需要授权的接口。

## 运行设置控制什么

例如，**队列容量**决定多少任务可以排队；**最大并发运行数**决定同一时间可以执行多少次。设置太小，任务可能一直等待；设置太大，机器可能忙不过来。先读取当前设置，只调整你确实需要的字段。

通过 `GET /api/environment/settings` 读取，通过 `PUT /api/environment/settings` 保存。它影响后续运行，不会修改已经保存的流程图。

## 密钥像一张通行证

程序请求需要鉴权的 API 时，把密钥放在 `Authorization: Bearer` 请求头里。密钥可以限制到某个项目，也可以只给它运行或读取结果所需的权限。

第一次管理员密钥只能从本机创建。之后由管理员在控制台或密钥接口创建其他密钥。完整 Secret 只显示一次；轮换后，旧 Secret 不能继续使用。

密钥的接口与例外情况见[环境设置与密钥 API](/api/environment)。
