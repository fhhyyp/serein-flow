# 调试流程

普通运行会一直执行到结束。**调试**则可以在某个节点前停下来，让你看看输入是什么、已经走过哪些步骤，再决定继续还是只走一步。

## 断点是什么

断点是你选中的一个暂停位置。启动调试时，把节点 ID 放进 `breakpointNodeIds`。流程快走到这个节点时会暂停，你可以检查当时的数据。

如果不需要停在某个节点，也可以先启动调试，再观察会话状态。会话会有自己的 ID，同时关联一次运行；两者用途不同：会话 ID 用来发“继续、单步、停止”命令，运行 ID 用来看事件和输出。

## 每次操作怎么做

1. 读取调试会话，看它是否已经暂停。
2. 决定 **继续**、**单步**或**停止**。
3. 发送带 `commandSequence` 的命令。
4. 再读取会话，确认状态有没有变化。

`commandSequence` 是命令编号，同一个会话里的新命令要往上加。它能防止旧请求因为网络重试而重复执行。

第一次接触调试，先在控制台点击 **调试流程** 操作一遍会更直观。随后可按[调试会话 API](/api/debug)把相同步骤写进程序。
