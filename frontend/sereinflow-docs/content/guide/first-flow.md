# 创建第一个流程

新项目一开始是一张空画布。我们先放一个自带的脚本节点，让它返回数字 `0`，再运行一次。这样可以先弄清“编辑、保存、运行、看结果”这一整条路。

## 1. 新建项目

打开控制台，选择 **新建项目**，输入一个容易认出的名称。创建完成后会看到“主流程”画布。项目和空画布已经保存，但空画布还不能运行。

## 2. 放入脚本节点

在左侧 **节点库** 找到“脚本”节点，拖到主流程画布。这个自带节点默认写着 `return 0`，意思是运行时返回数字 `0`。第一次体验可以先不改代码。

选中节点，在右侧 **节点检查器** 把它设为 **流程入口**。入口就是执行从哪里开始。只有一个节点时，不需要画连接线。

## 3. 保存并运行

点击顶部 **保存**。如果“保存诊断”列出了问题，按提示修改，再保存。然后点击 **运行流程**。

运行被接受后，**运行输出** 会显示事件与载荷；**运行控制台** 会显示这次运行的状态。成功时状态为 `succeeded`。你可以点开运行记录，查看具体节点的结果。

## 4. 加上第二个节点

可以再拖入一个脚本节点，用流程连接把第一个节点连到第二个节点，然后保存、运行。这样就能看到节点按顺序执行。需要把一个节点的值交给另一个节点参数时，用数据连接；流程连接只决定执行顺序。
