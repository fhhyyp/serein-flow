# Overview

Think of SereinFlow as a path from design to execution:

```text
Project → Flow → Nodes and connections → Saved version → Run → Results
```

| Term | Meaning |
| --- | --- |
| Project | A place for flows and their node libraries. |
| Flow | The execution steps you draw. |
| Node | One action in a flow. |
| Version | Flow content saved or published at a point in time. |
| Run | One actual execution of a flow. |
| Public interface | A stable entry point for external callers. |

## Suggested reading order

1. [Projects and flows](/en/modules/projects-and-flows): where the canvas is saved.
2. [Nodes and libraries](/en/modules/nodes-and-libraries): what actions a flow can perform.
